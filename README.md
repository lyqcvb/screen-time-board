# 家庭作息看板（Screen Time Board）

一个给家长用的**家庭作息与屏幕时间管理看板**。它不靠提醒和说教，而是把节奏变成看得见的图形，让家长和孩子一起从数据里读出规律。

## 为什么做这个

市面上大量"防沉迷"工具思路都是拦截与限制：锁屏、计时弹窗、强制下线。这类工具把家长和孩子放在对立面，孩子很快学会绕过，家长则疲于盯着时间。

真正影响作息的是**节奏本身**：几点起、几点吃、几点睡、屏幕时间挤占了哪一段。把这些画出来，家长和孩子看到的是同一条时间线，"要不要早点睡"就从命令变成了可以一起讨论的观察。

## 功能

- **三餐与睡眠时段可视化** — 24 小时时间轴，睡眠、三餐、屏幕时间用不同色块铺在同一行，一眼看出作息结构
- **每日屏幕时间记录** — 数字加时间轴色块双重呈现，跨零点自动处理
- **周趋势对比** — 近 7 天屏幕时间柱状图 + 睡眠时长折线，双指标叠加在同一坐标系
- **本地数据持久化** — 全部数据存于浏览器 `localStorage`，不上传服务器，不需要账号
- **一键导出周报** — 生成纯文本周报，含每日明细、日均/极值统计、晚睡天数，可一键复制

## 使用

打开 `index.html` 即可，无需构建、无依赖。

或启动本地静态服务：

```bash
cd screen-time-board
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 交互说明

- 顶部日期导航可回看任意一天，"今天"按钮快速回到当天
- 表单填写起床/就寝/三餐时间与屏幕分钟数，点击"保存今日"
- 趋势图与周报基于所选日期往前 7 天实时计算
- 周报中的"晚睡"判定为 22:30 之后就寝

## 设计

温和的日式极简：米白底色（`#f7f4ee`）配柔和青绿（`#6fae9f` / `#3f7d70`），大字号（基准 17px），圆角卡片，低对比阴影。视觉目标是"放在餐桌上不刺眼"，而不是仪表盘那种高压感。

## 技术

纯前端：HTML + CSS + 原生 JavaScript（ES5 语法，无框架、无构建步骤、无外部依赖）。趋势图用原生 SVG 手绘。

## 文件结构

```
screen-time-board/
├── index.html    # 页面结构
├── styles.css    # 日式极简样式
├── app.js        # 数据管理、可视化、周报导出
└── README.md
```

## 数据格式

localStorage key：`screen-time-board-data`，结构：

```json
{
  "2026-10-22": {
    "wakeTime": "07:00",
    "sleepTime": "22:00",
    "breakfast": "07:30",
    "lunch": "12:00",
    "dinner": "18:30",
    "screenMinutes": 90
  }
}
```

## 边界与取舍

- 不做账号与多设备同步：目标用户是个别家长，本地存储足够且隐私更好
- 不做提醒推送：本项目刻意避开"管"的姿态，只做观察工具
- 屏幕时间记录为手动填写，而非自动统计：自动统计需要系统权限，会引入新的隐私问题
